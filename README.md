# Sprawlist

Трекер задач на матрице Эйзенхауэра. Задача — кружок на полотне: он растёт, пока
её не выполняют, и тем быстрее, чем важнее и срочнее квадрант, в котором он лежит.
Кружки расталкивают друг друга, так что переполненный квадрант видно без всяких цифр.

Одна статическая страница, без зависимостей и без сборки.

## Запустить локально

Достаточно открыть `index.html` в браузере. Если хочется по-нормальному, через сервер:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

## Опубликовать на GitHub Pages

```bash
git init
git add .
git commit -m "Sprawlist: первая версия"
git branch -M main
git remote add origin git@github.com:ВАШ_ЛОГИН/sprawlist.git
git push -u origin main
```

Дальше в репозитории: **Settings → Pages → Build and deployment → Source: Deploy from
a branch → Branch: `main` / `/ (root)` → Save.**

Через минуту страница будет доступна по адресу `https://ВАШ_ЛОГИН.github.io/sprawlist/`.
Каждый следующий `git push` в `main` обновляет её автоматически.

Свой домен добавляется там же, в **Settings → Pages → Custom domain**.

## Где хранятся задачи

В `localStorage` браузера. Из этого следует:

- на телефоне и на ноутбуке будут разные задачи — синхронизации нет;
- очистка данных сайта удалит задачи;
- в приватном окне ничего не сохранится, всё живёт до закрытия вкладки.

Рост учитывается и за то время, пока вкладка была закрыта: при загрузке страница
смотрит, сколько прошло с последнего сохранения, и досчитывает размер.

Для общего доступа с нескольких устройств понадобится бэкенд — например, Supabase
или Cloudflare D1. Функции чтения/записи (`loadTasks`/`saveTasks`,
`loadSettings`/`saveSettings`) собраны в начале скрипта — менять придётся только их.

## Настройки

Всё в панели «Настройки роста»: длительность «дня» (по умолчанию демо-режим —
20 секунд, чтобы рост был заметен сразу; для реальной работы поставьте «24 часа»),
начальный и предельный размер кружка, скорость роста для каждого квадранта.
